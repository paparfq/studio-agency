# 08 — KPI & Keuangan

## KPI bisnis
| KPI | Definisi | Target (ASUMSI) |
|---|---|---|
| MRR | Total retainer per bulan | Rp__ jt di bulan ke-6 |
| Klien retainer aktif | Jumlah | __ |
| Churn | % klien retainer berhenti / bulan | < 10% |
| Margin kotor | Per paket | ≥ 50% |
| CAC | Biaya akuisisi per klien | < 1× nilai bulan pertama |
| Konversi pilot → retainer | % | ≥ 50% |
| Utilisasi tim | Jam billable / jam tersedia | 60–80% |

## KPI klien (dilaporkan)
- Tahap 1: telepon, permintaan rute, rating, jumlah ulasan
- Tahap 2: repeat customer, member aktif, chat WA masuk, CPL/ROAS iklan
- Tahap 3: omzet per cabang, partner baru

## Break-even
```
Break-even bulanan = Biaya tetap bulanan / Rata-rata margin kotor per klien
```
