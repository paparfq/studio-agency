# 09 — Risiko & Kebijakan

## Kebijakan platform (wajib)
- Dilarang review palsu, review berinsentif, dan *review-gating* (hanya meminta ulasan dari pelanggan yang puas). Google/Shopee/TikTok bisa men-suspend akun.
- Dilarang beli followers/engagement.
- Iklan mematuhi kebijakan Meta/TikTok (klaim kesehatan, before-after, dll.).

## Risiko bisnis
| Risiko | Mitigasi |
|---|---|
| Scope creep | Scope tertulis, revisi dibatasi, biaya tambahan jelas |
| Telat bayar | DP 50%, retainer bayar di muka, file final setelah lunas |
| Tergantung 1 orang | SOP, template, freelancer cadangan |
| Klien churn cepat | Kontrak min. 3 bulan, laporan KPI rutin |
| Perang harga | Jual hasil & studi kasus, bukan harga termurah |
| Hasil iklan buruk | Ekspektasi realistis di awal, uji kecil dulu |
