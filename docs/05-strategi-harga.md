## Rumus tarif minimum
```
Tarif per jam minimum = (Biaya bulanan + Target profit) / Jam billable per bulan
Harga paket           = Estimasi jam × Tarif per jam (+ biaya tools/freelancer)
Margin kotor          = (Harga − Biaya langsung) / Harga   → target ≥ 50%
```
Jam billable realistis ≈ 60–70% dari jam kerja (sisanya sales, admin, revisi).

## Aturan harga
- DP 50% untuk proyek, pelunasan sebelum file final
- Retainer: kontrak minimal 3 bulan, dibayar di muka tiap bulan
- Revisi 2x termasuk, selebihnya biaya tambahan
- Rush fee +30%
- Ad spend dibayar langsung oleh klien ke platform
- Diskon hanya untuk: pilot (maks. 30%, ditukar testimoni + izin studi kasus) atau bayar retainer 6 bulan di muka (maks. 10%)

## Strategi
- Tiga tier per layanan (Basic / Standar / Pro): pasang tier tengah sebagai pilihan utama
- Entry product murah untuk membuka hubungan, profit dari retainer
- Jual hasil (telepon, rute, repeat order), bukan jam kerja
- Review harga tiap 3 bulan atau setiap kapasitas > 80%
