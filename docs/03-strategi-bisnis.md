# 03 — Strategi Bisnis

## Tangga layanan
**Entry** (murah, hasil cepat terlihat) → **Proyek inti** → **Retainer** (pendapatan berulang)

## Model tahap klien (berdasarkan kondisi bisnis klien)
| | Tahap 1: Ditemukan | Tahap 2: Dipilih & Kembali | Tahap 3: Berkembang |
|---|---|---|---|
| Kondisi | 1 outlet, walk-in + mulut ke mulut | Pelanggan stabil, mau tambah omzet | 2+ cabang / rencana franchise |
| Masalah | Orang tidak tahu bisnisnya ada | Pelanggan datang sekali lalu pindah | Cabang tidak konsisten |
| Studio | Foto Google Maps, brand dasar (logo, signage, nota) | Template konten, promo, kartu member | Brand guideline, standar outlet, franchise kit |
| Agency | Sistem review patuh aturan | Sosmed + Meta Ads radius lokal, CRM WA | Strategi multi-cabang |
| KPI | Telepon, rute, rating | Repeat customer, member aktif | Omzet per cabang |
| Harga | Proyek murah + retainer ringan | Retainer bulanan | Proyek besar + retainer |

**Pemicu naik tahap:** rating ≥ 4,5 dengan ulasan cukup → Tahap 2. Cabang kedua / pertanyaan franchise → Tahap 3.

> Bukan urutan kaku. Branding dibutuhkan di semua tahap dengan kedalaman berbeda.

## Titik masuk per segmen
| Segmen | Mulai dari |
|---|---|
| Jasa lokal | Tahap 1 — Google Maps dominan |
| F&B / kafe | Tahap 1+2 — TikTok/IG untuk discovery, Maps untuk verifikasi, GoFood/GrabFood |
| Produk online | Tahap 2 — Shopee/TikTok Shop + sosmed; Maps hampir tidak relevan |

## Prioritas 90 hari
1. Satu segmen, satu kota, satu paket entry
2. Bukti hasil (pilot) sebelum scale iklan sendiri
3. Konversi ke retainer
